# CyberTracker

- Status: `curated`
- Region / reach: global (Cape Town, South Africa origin; used by Indigenous communities and community-science projects worldwide)
- Project: free field data-capture software for smartphones/handhelds, developed since 1997 by CyberTracker Conservation (non-profit Public Benefit Organisation); companion Tracker Certification preserving Indigenous tracking skills
- Field-guide context: opened via the A5 northern/remote food systems scan (G-OSA-39); verified 2026-09-09 against cybertracker.org
- Record type: software record — the oldest continuously-maintained open field-data tool serving Indigenous knowledge systems

## Problem addressed

Expert trackers (the Kalahari San origins are the founding case) hold knowledge that paper forms and scientific protocols can't capture without stripping its structure. Field data capture needs to work offline, in the tracker's own language and iconography, at zero cost to the community.

## What it does

CyberTracker's screen interface lets users build icon-driven data-collection sequences usable by non-literate and multi-lingual trackers; data syncs when connectivity allows. Its stated objective: "to provide a free service to Indigenous Communities, Community Science (Citizen Science), Humanitarian projects and students, while covering our costs with payments from high-volume users" (verified from cybertracker.org/pricing, 2026-09-09). The Kalahari Tracker Project funds R&D with the communities that originated the method.

## Open layer — verified with an important status change

- **Software**: CyberTracker Mobile's current codebase is public on GitHub — **CyberTrackerConservation/ctmobile, MIT licence (verified via GitHub API 2026-09-09, last push 2026-06-12)**.
- **Hosting model change, recorded honestly**: the *Online* platform (server-side data hosting) moved to a tiered payment model — ZAR350–3400 (~US$20–200)/year by observation volume — with **free access on application for Indigenous communities, community science, humanitarian projects and students**. The WIPO profile notes that up to 2025 the software was simply freely downloadable. The open-software layer survives (MIT mobile client); the *hosting* layer is now tiered-priced with a free lane — a hybrid of the corpus's "pooled/fee-for-volume funding" maintenance archetypes rather than a pure commons.

## Why it belongs

1. It is the **lineage root of the northern food-monitoring stack**: Nunavut's CBMN harvesters record the country-food system's wildlife data on CyberTracker-lineage tools (the MESAs and the app generation that followed).
2. Its founding design problem — Indigenous knowledge capture in the tracker's own epistemology — makes it the earliest software built *for* Indigenous knowledge systems rather than around them.
3. The 2025–26 hosting-price change is a live instance of the corpus's core maintenance question: an open client with a funded-server commons that introduced a sliding scale to survive. The pooled-funding-circle archetype (Foodsoft/Democratic Tech Fund) has a new data point.

## What it does not demonstrate

- That the full platform (Online server code) is open — only the mobile client's MIT status is verified; server-side source was not located.
- Current deployment scale in northern Canada specifically (CBMN's usage is documented; other Canadian deployments not counted here).
