# FarmStack (Digital Green)

- Status: `curated`
- Region / reach: global (origin US nonprofit; deployments including Kenya and Ethiopia)
- Project: https://www.farmstack.co/ ; DPG profile: https://www.digitalpublicgoods.net/r/farmstack
- Field-guide context: new discovery from the DPI-for-agriculture cycle, 2026-08-02

## Problem addressed

FarmStack is an open-source product suite enabling the secure transfer of data across the agricultural ecosystem. It is a reference implementation of an open, interoperable data-sharing protocol for agriculture — the data-exchange building block on which digital public infrastructure for agriculture can be assembled, connecting farmers, organisations, and services without proprietary data silos.

## Open layer

Open-source data-exchange protocol and reference implementation: open API data sharing between organisations and farmers, positioned as a Digital Public Good (DPG) and used as a DPI building block (e.g., powering data transfer in agriculture in Ethiopia).

## What is actually open

- Licence: Apache-2.0, verified via the Digital Public Goods Alliance registry (DPG since 07.08.2022; last evaluated 06.02.2025; DPG ID GID0090034).
- Repositories: digitalgreenorg/farmstack-backend (last push 2025-07) and digitalgreenorg/farmstack-frontend (last push 2025-05); small community (4-6 stars, 16 contributors on the frontend) — active but not a large-community project.
- DPGA-verified indicators include open licences, clear ownership, documentation, and non-PII data extraction; several indicators are self-reported by the owner.
- The World Bank/Co-Develop DPI-for-agriculture report lists FarmStack as a DPG data-exchange product, alongside AgriJSON (C4IR/WEF data standard) and India's UFSI.

## Governance and control

Owned by Digital Green, a US-based nonprofit. Data-sharing governance is protocol- and consent-based (organisations and farmers control transfers); the project is not farmer-governed, but its stated aim is to put farmers at the centre of the agricultural data ecosystem.

## Evidence of use

- DPGA registry: self-reported organisations using it include the Kenya Agricultural and Livestock Research Organization (KALRO).
- LinkedIn/Dial material describes FarmStack as a DPG implemented as DPI in Ethiopia for agricultural data transfer.
- GitHub activity confirms ongoing (if modest) development into 2025.
- Deployment scale and farmer-level outcomes are not independently documented in this pass.

## Maintenance and funding

Nonprofit-owned (Digital Green), with DPG status providing visibility; the project sits in the DPI-for-agriculture ecosystem funded by development actors (e.g., Gates Foundation-adjacent initiatives per the World Bank/Co-Develop report's framing). Community size is small, which is a maintenance risk.

## What this case demonstrates

FarmStack is the strongest located example of an open-source data-exchange building block for agriculture: an Apache-2.0 DPG whose role is to make agricultural data sharing protocol-level open, usable as DPI across countries. It connects this collection's data-governance thread (OADA, JoinData) to the DPI paradigm.

## What it does not demonstrate

- It does not establish deployment scale or farmer-level outcomes; the KALRO usage is self-reported.
- DPG verification covers the listed repositories, not every add-on.
- It is protocol infrastructure, not farmer-governed data governance.
- Community size is small; maintenance beyond the owner organisation is unverified.
