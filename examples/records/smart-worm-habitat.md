# Smart Worm Habitat (danielneil/Smart-Worm-Habitat)

Status: candidate
Region/reach: Hobby / home-scale vermicomposting; individual developer (danielneil); global via GitHub
Project links:
- GitHub repo: https://github.com/danielneil/Smart-Worm-Habitat
- GPL-3.0 license file in repo

Problem addressed: designing an open-source continuous-flow-through vermicompost system that converts food waste into vermicast (worm castings), with built-in sensors to monitor the health of the system (moisture, pH, temperature) and alerts when worms are in distress — with an emissions-reduction framing (diverting food waste from landfill).

Open layer: open-source hardware + software concept — GPL-3.0 licensed, with engineering design documents, CAD concept images, and sensor integration described in the repo.

What is actually open (asset by asset, licences verified):
- Code/software: GPL-3.0 license (verified in repo LICENSE file).
- Hardware design documents: engineering folder with design docs, including a continuous-flow-worm-bin design document; CAD concept images in images/ folder.
- Design concept: continuous-flow-through (CFT) vermicompost system — worms undisturbed in upper layers, vermicast harvested from below; sensors for outside temperature, inside temperature, soil moisture, soil pH.
- Documentation: README with design intent, "how is it smart," emissions-reduction claims (1,368 kg CO2-e/month diverted), alert system description; doc/ folder with "what does open source mean" and "mantra" documents.
