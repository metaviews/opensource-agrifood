# JoinData

- Status: `curated`
- Region / reach: Netherlands
- Project: https://join-data.nl/en/
- Field-guide context: `units/joindata-netherlands.md`

## Problem addressed

JoinData addresses opaque agricultural data permissions and the difficulty farmers face in knowing who can access or use their data.

## Open layer

Farmer-facing data governance, permission management, and cooperative-oriented infrastructure. JoinData is not treated here as an open-source software project in the same sense as OADA or ODK.

## What is actually open or commons-oriented

The platform provides an overview of permissions, purpose-bound access, revocation, and encrypted transfer. The current public materials support a claim about farmer-facing control, not necessarily about open code or open data.

## Governance and control

JoinData’s stated mission is to put farmers “behind the wheel.” Farmers can see which entities have access and revoke authorisations.

## Evidence of use

The current site documents an operational platform. A 2023 Development Gateway / USAID case study provides historical membership and operating-model evidence. Those figures should not be reused as current scale without rechecking.

## Maintenance and funding

The case study identifies an operating and fee model; current governance, membership, and financial structure require updating.

## Why it belongs

JoinData is a useful counterweight to software-centred definitions of openness. It asks whether data subjects can exercise meaningful permission and control even when the platform itself is not an open-source project.

## What it does not demonstrate

JoinData does not establish a globally transferable cooperative model, open software, or current adoption beyond the evidence documented in its sources.
