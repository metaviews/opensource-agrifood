# All Farmers Code (全农码 / QuanNongMa)

- Status: `candidate`
- Region / reach: China / national; agricultural digital identity platform
- Project: co-developed by MARA Big Data Development Center + Zhejiang Oracle Supercode Technology (chaojima); company page: https://www.chaojima.com/appH5/aboutUs.html
- Field-guide context: extends the China ag digital infrastructure record (china-ag-data-infrastructure.md)

## Problem addressed

China's agricultural data lacks unified digital identity across people, land, and products. The All Farmers Code gives agricultural entities a unified digital identity (QR code / NFC / RFID), enabling data rights confirmation, tiered authorization, and traceability from production to consumption — the operational layer of the Smart Agriculture Action Plan 2024-2028's "All Farmers Code" target.

## Open layer

None verified. This is a closed state-private digital identity platform; it is carried in the collection as the implementation evidence for G-OSA-19 (the plan's named deliverable) and as a governance case, not as an open project.

## What is actually open

Nothing located: no APIs, licences, or data-access terms published. The platform's "openness" layer is the plan's framing of a shared data foundation; the operational reality is a private operator under a MARA joint-lab agreement.

## Governance and control

State-private co-production: MARA Big Data Development Center signed a joint-lab agreement (2022) with Zhejiang Oracle Supercode Technology (chaojima, Hangzhou; "national-level specialized little giant" enterprise, quasi-unicorn), which describes itself as co-developer and operator of the All Farmers Code national platform. Zhejiang province runs the pilot linkage (浙农码↔全农码). Farmer agency: not addressed in located framing; no consent or benefit measurement located (G-CN-02).

## Evidence of use

Company-reported (2026-06): 14 provincial applications, 101 local applications, 360+ agricultural services integrated, 700M+ cumulative code uses, 20M+ mu farmland served, 12,000+ modern farms. The platform launched 2023 (孙姗 2024). All figures are vendor self-reports; independent verification not located.

## Maintenance and funding

State-adjacent commercial: MARA joint lab + private company operations; the company is venture-backed and state-certified. This is the venture/state hybrid archetype — maintenance assured by commercial capital, governance and benefit the contested axes.

## Why it belongs

The All Farmers Code is the named deliverable of the Smart Agriculture Action Plan (G-OSA-19) and now has implementation evidence: it exists, launched in 2023, and is operated by a private company under a MARA joint lab. It is the clearest located case of China's state-private agricultural data platform reality — and a boundary case: "national platform" framing with private operation and zero verified openness.

## What it does not demonstrate

It does not demonstrate openness (no APIs, licences, or data access), farmer agency (no consent or benefit evidence), or independently verified scale (all usage figures company-reported). It demonstrates implementation, not openness.
