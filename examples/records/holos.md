# Holos — Agriculture and Agri-Food Canada

- Status: `candidate`
- Region / reach: Canada; federal public research and extension infrastructure
- Repository: https://github.com/holos-aafc/holos
- Field-guide context: Canadian discovery lead; not transferred from the Agrifood AI Field Guide

## Problem addressed

Holos is a whole-farm greenhouse-gas emissions model and decision-support software project associated with Agriculture and Agri-Food Canada.

## Open layer

Open-source model algorithms, software code, documentation, tests, installers, and bilingual contribution materials.

## What is actually open

The public repository describes itself as the open-source version of the core algorithms used by the Holos model. It states that source code is distributed under GPLv3 unless otherwise noted, while Canada wordmarks and related graphics remain protected. The repository contains application and test projects, algorithm documentation, English and French contribution files, and installer artefacts. The README explicitly says that the Holos 4 graphical user interface is not open source at this time, so the open status should be understood as an open core rather than a fully open GUI stack. AAFC’s programme page says the team is preparing the model for collaborative development and seeking external expertise.

## Governance and control

The repository identifies Crown Copyright and federal institutional ownership. Public source access creates technical inspectability and reuse rights under GPLv3, but it does not by itself establish farmer participation in priority-setting or control over model parameters and datasets.

## Evidence of use

The AAFC programme page says Holos is continually updated, available in English and French, and available at no cost. It welcomes feedback from researchers, farmers, and industry. Repository activity establishes public development, not farmer adoption, emissions reductions, or advisory impact.

## Maintenance and funding

Holos is maintained in a federal public-research context. The long-term relationship between public funding, federal programme priorities, community contributions, and downstream users requires further verification.

## Why it matters

Holos is a strong Canadian public-sector open-source case. It adds agricultural climate and emissions modelling, and it provides a useful contrast with public data catalogues and farmer-facing software.

## What it does not demonstrate

Open model code does not guarantee open input data, transparent parameter governance, reproducibility across farms, farmer control, or climate impact.
