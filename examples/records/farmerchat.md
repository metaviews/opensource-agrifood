# FarmerChat (Digital Green)

- Status: `curated`
- Region / reach: India, Kenya, Nigeria, Ethiopia, Brazil (5 countries); languages incl. English, Hindi, Telugu, Amharic, Kiswahili, Hausa, Portuguese, Spanish
- Project: https://github.com/digitalgreenorg/DG_Open ; datasets: https://huggingface.co/datasets/DigiGreen/farmerchat-queries-large ; app: https://play.google.com/store/apps/details?id=org.digitalgreen.farmer.chat
- Field-guide context: none

## Problem addressed

Smallholder farmers need timely, localized advice but extension reach is thin (one agent per ~3000 clients in SSA). FarmerChat is an AI assistant delivering personalized, grounded farm advice at scale — reported at 1.6 million farmers across five countries (FAIR Forward catalog, checked 2026-08-02).

## Open layer

Open foundation: Apache-2.0 codebase (github.com/digitalgreenorg/DG_Open), CC-BY-4.0 datasets (Hugging Face farmerchat-queries-large), agronomist-reviewed content pipeline with human review before deployment in new crops/geographies. The running service is a managed platform with partnership tiers (open-build, community, custom) — openness attaches to the foundation, not the deployment.

## What is actually open

Verified via the FAIR Forward / GIZ project catalog (checked 2026-08-02): code Apache 2.0 (13 stars), datasets CC-BY 4.0 (181 Hugging Face downloads), documentation in-depth, links healthy, recently updated (last commit Nov 2025). Digital Green publishes and maintains the open-source foundation; partners own their deployments.

## Governance and control

Nonprofit (Digital Green) with multi-funder support (Rockefeller Foundation, Gates Foundation, BMZ, Sequoia Climate Fund, CISCO Foundation); catalyzed in parts by FAIR Forward (GIZ). Farmer data governance per Digital Green's nonprofit model; the deployed service remains organization-managed.

## Evidence of use

1.6M farmers across five countries (FAIR Forward, 2026-08-02); Android app live; query dataset published. The largest verified deployed open-data agricultural AI system located in this project — the first with an explicit denominator (G-OSA-11's requirement).

## Maintenance and funding

Nonprofit + foundation funding; platform maintained by Digital Green staff; open-community uptake modest (13 stars / 181 downloads) — the maintenance model is organizational, not community-scale.

## Why it belongs

FarmerChat is the deployment anchor for the open-language-data layer (G-OSA-03) and the strongest evidence that open-data agricultural AI reaches farmer scale — with the caveat that openness is foundational, deployment is managed. Same organization as the collection's FarmStack record.

## What it does not demonstrate

FarmerChat does not demonstrate open-model deployment (the service is managed), independent farmer-benefit verification, or community-scale maintenance; 1.6M farmers reached ≠ measured farmer benefit (G-CV-01).
