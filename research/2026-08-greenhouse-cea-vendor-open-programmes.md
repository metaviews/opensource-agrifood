# Scan: Vendor "open" programmes in greenhouse climate control — G-OSA-22 residual pass

Research date: 2026-08-06
Method: bounded follow-up pass (G-OSA-22 residual item 2); 4 targeted query sets (Priva, Hoogendoorn/IIVO/LetsGrow.com, Ridder/Argus/climate-computer APIs, Signify/Philips horticulture lighting); 2 primary sources read in full (Priva "Integrate greenhouse data" page; Priva "API must add value" blog, 2024-12-20). Purpose: close the contested "open system architecture" claim flagged in research/2026-08-greenhouse-cea-open-automation-scan.md.

## Headline finding

**Climate-computer vendor "open" claims resolve to open *interfaces*, never open *licences*: Priva — the only major climate-computer vendor with a substantive public open-integration programme — operates an API + developer portal gated by a Priva Connected subscription and an approved "Priva Integration Partners" ecosystem, with zero open-source licence disclosed; its CEO states the ambition to become "the App Store of horticulture." Hoogendoorn, Signify, Ridder, and Argus surfaced no public open-source or open-API programme in this pass. The commercial control layer's "open" vocabulary is integration-openness marketing, not openness in the licence sense the corpus records. C-OSA-06 resolves accordingly: interface-open, licence-closed.**

## What the vendor pass verified (primary sources)

### Priva (De Lier, NL) — the substantive open-interface case
- "Priva's open platform": data shared "securely with other service providers (Priva Integration Partners)" — an approved-partner ecosystem, not an open commons. Partners named on the page: Blue Radix, Source.ag, IUNU.
- Access requirements: Priva Gateway hardware + Priva Connected subscription + API Services; documentation on the Priva Horticulture Developer Portal (horti.developers.priva.com). ISO 27001/9001-certified infrastructure.
- Data ownership: vendor states "all data remains yours" / customer retains ownership — a data-ownership claim that is itself vendor-stated, not licence-verified.
- CEO Hans Peters (GreenTech Amsterdam 2024, via GroentenNieuws): "We want to become the App Store of horticulture." Strategic Business Manager Dirk Prins: "Priva's Open Platform and API links open a lot of doors… makes the full potential of data available to the market."
- **No open-source licence, no open governance, no public data format standard.** Open = API + partner agreements + subscription.

### Hoogendoorn (NL) — IIVO + LetsGrow.com
- IIVO climate computer: proprietary, predictive climate control ("Connecting nature and technology with IIVO").
- LetsGrow.com: described in a third-party industry overview (Chang 2020, "Digital Horticulture") as an "open software platform that connects available data from the greenhouse and presents it in a user-friendly way in a dashboard" — "open" in the connects-any-data sense; no open licence located; the 2025 Grodan–Hoogendoorn GroSens integration is a closed B2B partnership.
- **No open-source or open-API programme located.**

### Signify / Philips Horticulture LED
- GrowWise control: closed spectral-light control + energy trading (2025 press release); GreenPower LED hardware.
- **No open claims at all located.**

### Ridder / Argus / other climate-computer vendors
- No open API or open-source programme surfaced in this pass (thin public record; not exhaustively verified — see "what this doesn't do").

## Contested-claim resolution

- **C-OSA-06: "Priva has an open system architecture" / vendor "open" claims in greenhouse control.**
  - Asserter: Priva marketing ("Priva's open platform", "open integration platform", "open system architecture supports diverse hardware" per industry listings).
  - Contester: primary-source licence check — no open-source licence; API gated by subscription + approved-partner agreements; platform governance retained by Priva; "App Store of horticulture" ambition is enclosure-by-integration framing, not commons framing.
  - **Verdict: interface-open, licence-closed.** The interface reading is evidenced (API + developer portal + partner ecosystem); the licence reading is rejected. Matches the corpus's openness-discipline phrase: open system ≠ open licence.

## What this doesn't do (honest omissions)

1. Does not exhaustively audit Ridder, Argus, Wadsworth, or regional climate-computer vendors' developer programmes — the negative for these is "not surfaced in this pass," not "confirmed absent."
2. Does not assess whether Priva's partner ecosystem is actually open to any applicant or de facto curated; the "approved" wording suggests curation but partner-admission criteria are not public.
3. Does not verify the vendor data-ownership claims ("all data remains yours") against licence or contract terms — a G-OSA-16-adjacent question, not resolved here.
4. Does not cover LetsGrow.com's terms of service in depth; the "open software platform" usage (Chang 2020) is flagged as contested vocabulary, not verified as an open licence.
